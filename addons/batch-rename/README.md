# Batch Rename / 批量重命名

**Status / 状态:** Planned / 规划中 — **no runnable script yet / 暂无可运行脚本**.

**Proposed goal / 计划功能:** Rename multiple selected scene components in Visual Components with configurable prefixes and numbering while preserving distinct names.
