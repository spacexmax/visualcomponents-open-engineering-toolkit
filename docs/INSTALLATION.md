# Installing add-ons / 插件安装说明

> **No installable add-ons have been released yet. / 当前没有可安装的插件。**

When a release becomes available / 正式发布后：

1. Open this repository's **Releases（版本发布）** page.
2. Choose the specific add-on and the ZIP package matching your Visual Components version.
3. Read that add-on's README（说明文件） and release notes before extracting.
4. Close Visual Components if the add-on's instructions require it.
5. Back up the destination folder and the simulation/layout you intend to test.
6. Install into the correct user add-on/command location **specified by that tested release**; paths depend on product release and scripting environment.
7. Restart or refresh Visual Components as instructed and test with a sample layout first.

Do **not** blindly copy an add-on for VC 5.0 into VC 4.10 or vice versa. Do not run unverified scripts against production or customer CAD data.

**源码 ZIP 与安装包的区别：** GitHub 的 `Code → Download ZIP` 下载的是整个仓库源文件，不等于已经验证过的插件。优先使用 Releases 中明确标注版本的安装包。
