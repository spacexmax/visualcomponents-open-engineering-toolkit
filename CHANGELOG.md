## 2026-11-22 — Blenderer 2.6.0 XG V1

**Released / 已发布：** [Blenderer XG V1 (VC 4.10)](https://github.com/spacexmax/visualcomponents-open-engineering-toolkit/releases/tag/blenderer-xg-v1-vc410) · [Complete FULL.zip / 完整安装包](https://github.com/spacexmax/visualcomponents-open-engineering-toolkit/releases/download/blenderer-xg-v1-vc410/Blenderer-2.6.0-XG-V1-VC4.10-FULL.zip)

- Added XG V1 source code, Chinese/English documentation, installation guidance, and a complete download package containing code and rendering assets.
